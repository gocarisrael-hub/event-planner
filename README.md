# Ocar Fun Day Builder · בונה ימי כיף

A tool for **Ocar** to plan **fun days** and **ימי גיבוש** for companies and the IDF, then export a
polished Hebrew (RTL) PDF for the client — with or without prices.

## What it does

1. **New day** — enter a short brief: group size, who they are, what they want, budget, and a
   date / month / season.
2. **Schedule builder** — build the day as a vertical schedule. Type an activity to add it instantly;
   set an approximate time, a duration, a free-text time note ("בוקר, בערך 8–10"), vendor, a price
   **range**, and photos. Drag to reorder. A budget meter shows the running total vs. the budget.
3. **Reusable catalog** — every activity you add is **saved to the catalog automatically**, so the
   next day is faster to build. Manage activities and vendors under *קטלוג* / *ספקים*.
4. **Proposal PDF** — a branded, print-ready Hebrew page. Toggle prices on/off and **Download PDF**
   (via the browser's *Save as PDF*).

## Run it

```bash
cd event-planner
npm install        # installs client + server (npm workspaces)
npm run dev        # client on http://localhost:4000, server on http://localhost:4001
```

Open http://localhost:4000.

## Branding

Drop your logo in `assets/logo/`, copy it to `server/assets/ocar-logo.png`, then set
`logoUrl: '/brand/ocar-logo.png'` and your colors in `client/src/brand/brand.js`
(also `client/tailwind.config.js`).

## Tech

- **client/** — React + Vite + Tailwind + Zustand + React Router (+ dnd-kit for reordering).
- **server/** — Express + Multer (photo uploads). Data is a JSON file at `server/data/app.json`.

### Implementation notes / future upgrades

Two pragmatic choices keep install reliable on bleeding-edge Node:

- **Data:** a small JSON-file store (`server/db.js`) instead of SQLite — no native build. Easy to
  swap for SQLite/Postgres when hosting.
- **PDF:** generated by the browser's print-to-PDF on the styled `/day/:id/proposal` page (perfect
  Hebrew/RTL/photos, zero extra deps). Can be upgraded to server-side Puppeteer for one-click
  downloadable files later.
